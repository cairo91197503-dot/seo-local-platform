# Instruções para Agentes

Este repositório foi preparado para desenvolvimento assistido por IA.

## Comece por aqui

Antes de trabalhar no projeto, leia nesta ordem:

1. `.ai/context.md` — produto e objetivos

2. `.ai/stack.md` — tecnologias e arquitetura

3. `.ai/rules.md` — regras de desenvolvimento

4. `docs/` — documentação detalhada

Não assuma requisitos que não estejam documentados.

## Projeto

O produto está em fase inicial de reconstrução.

O objetivo é criar uma plataforma brasileira que combine educação, gamificação, inteligência artificial e ferramentas práticas para ajudar pequenos negócios a melhorar sua presença local no Google.

O nome comercial definitivo ainda não foi escolhido.

## Desenvolvimento

Faça mudanças pequenas, justificadas e verificáveis.

Não introduza novas tecnologias ou dependências sem necessidade.

Nunca coloque credenciais, tokens, chaves privadas ou outros segredos no repositório.
